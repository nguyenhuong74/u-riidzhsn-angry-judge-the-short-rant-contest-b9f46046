One short, funny rant about a small everyday annoyance — the office printer that only ever breaks for you.

## The rant

> The office printer works perfectly all day — until I need one page before a meeting. Then it jams, flashes an error code nobody has ever seen, and spits out my document in a language I don't speak. IT says 'turn it off and on again' like it's a magic spell. It works. And now I'm late, and the printer is smug.

## Why this rant works

It picks one concrete, universal villain — the office printer — and gives it a personality: it works fine all day, then sabotages you at the exact worst moment, like it planned it. The escalation is fast and specific (a mystery error code, a document in a language you don't speak), the IT punchline lands on a phrase everyone has actually heard, and the final twist turns the machine into the smug one while you're the one who's late. No throat-clearing, no list of complaints — just one bad morning, told in five sentences.

## Run it

```sh
node main.ts
```

This validates the rant (1–400 characters, non-blank, valid UTF-8) and writes it deterministically to `/output/entry.txt`. No dependencies, no network, no randomness — the same output every run.
